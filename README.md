# OnlineBanking

Project description for students: In this project, you will create an online banking program. Users need to have an account number and PIN to identify themselves as owners of an account. Once users enter the system they will have standard options: check balance, deposit, and withdraw. Additionally, a new user or bank administrator can also create a new account, close an account, and modify an account (such as editing name, PIN, or any other personal identification required to open an account).


Project Directions:
Step 1: Download and install VSCode, and MySQL, and then create a GitHub repo for the project.  Be sure to commit and push your changes often throughout the project.  This will keep your code safe in case of local computer crashes!  You’ll also have a history of changes you made.
Step 2. Get familiar with SQL. Create a database in MySQL.
Step 3: Define data structure/table(s) for users and populate with data, at least one admin user and one customer.  
Step 4: Create all the functions that will be needed to handle the requests (make sure you utilize header files to organize your code) and create the tables needed for account data
Step 5: Create some sort of visual for the app. This can be a text-based, CLI menu, it can be a simple UI created in something like Tkinter, or it can be on a webpage using something like Flask
Step 6: Write tests for all the functions


Weekly Lesson Topics
Week 1 - Setup for VS Code and MySQL. A quick discussion of databases
Week 2 - SQL queries, using databases, Python-MySQL Connector
Week 3 - Work session for functions and UI
Week 4 - Sharing projects for feedback


Weekly milestones:
By the end of week 1: Students have successfully created a GitHub project, set up their coding environment (VSCode + MySQL), and created a basic welcome message and menu for their app.
By the end of week 2: Students have created SQL tables needed for the app and have successfully created all (or most) functions for all tasks (check balance, deposit, withdraw, create account, delete account, modify account) and create tables for account data.
By the end of week 3: Students have finished creating all of the functions for the task created a UI for all remaining tasks and have written tests for all functions
By the end of week 4: The app should be functional and meet all requirements

# Pass Criteria

Submissions for this course will be evaluated on a pass/fail basis, focusing on the completeness of your attempt and your engagement with the project components, rather than the perfect functionality of the final product. To receive a passing grade, students must demonstrate a genuine effort in addressing all of the following key components of the project:
As long as you have a submission with a genuine attempt at completing the project as outlined below, you will receive a passing grade.
Database Implementation:
Implement a functional database using MySQL Workbench or SQLite


Function Development:
Develop and attempt to implement the core functionalities required for the banking operations such as account management (creation, modification, closure), and transactional operations (checking balances, making deposits, withdrawals).
Organize your code logically, focusing on making it readable (use comments).
User Interface (UI):
Design and implement a user interface to allow users to interact with the banking system using tools such as CLI, Flask, Tkinter, etc. 


Testing:
Write and provide basic tests for the major functions you have developed. 


Additional Notes:
Projects do not need to be fully functional to pass; however, there should be clear evidence of a substantial attempt to meet the project's requirements and tackle the problems presented.
Be sure to add comments throughout your code to document what each piece of code does as well as your thought process
